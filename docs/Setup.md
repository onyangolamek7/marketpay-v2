# Project Setup

## Django
1. `cd backend/django-api`
2. `python -m venv venv`
3. `venv\Scripts\activate`
4. `pip install django djangorestframework`
5. `python manage.py runserver`

## Rust
1. `cd backend/rust-services/wallet-service`
2. `cargo run`

## Next.js
1. `cd frontend/web-nextjs`
2. `npm install`
3. `npm run dev`

## Docker
1. `docker-compose up --build`
